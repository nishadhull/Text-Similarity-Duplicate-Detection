# 🔍 Text Similarity & Duplicate Question Detection

## About the Project
This project is an NLP and Machine Learning-based web application designed to identify duplicate or semantically similar questions.

It uses the Sentence-BERT model to understand the meaning of two sentences and calculate their semantic similarity.

# 🔍 Text Similarity & Duplicate Question Detection ## About the Project This project is an NLP and Machine Learning-based web application designed to identify duplicate or semantically similar questions. It uses the Sentence-BERT model to understand the meaning of two sentences and calculate their semantic similarity. ## Live Demo Visit the deployed application: PASTE YOUR STREAMLIT WEBSITE LINK HERE ## Features - Compare two questions. - Detect duplicate and similar questions. - Calculate semantic similarity scores. - Sentence-BERT model integration. - Interactive web interface. - Real-time similarity checking. ## Technologies Used - Python - Machine Learning - Natural Language Processing - Sentence-BERT - Streamlit - Scikit-learn - Pandas - NumPy ## Project Structure - app.py – Main Streamlit application. - train.py – Model training. - preprocessing.py – Text preprocessing. - feature_engineering.py – Feature engineering. - dataset/ – Project dataset. - model/ – Model files. - screenshots/ – Application screenshots. ## How to Run 1. Clone the repository. 2. Install the required dependencies: pip install -r requirements.txt 3. Run the application: streamlit run app.py ## Developer Nisha Dhull B.Tech CSE (AI & ML)

## Features
- Compare two questions.
- Detect duplicate and similar questions.
- Calculate semantic similarity scores.
- Sentence-BERT model integration.
- Interactive web interface.
- Real-time similarity checking.

## Technologies Used
- Python
- Machine Learning
- Natural Language Processing
- Sentence-BERT
- Streamlit
- Scikit-learn
- Pandas
- NumPy

## Project Structure
- app.py – Main Streamlit application.
- train.py – Model training.
- preprocessing.py – Text preprocessing.
- feature_engineering.py – Feature engineering.
- dataset/ – Project dataset.
- model/ – Model files.
- screenshots/ – Application screenshots.

## How to Run

1. Clone the repository.
2. Install the required dependencies:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py
